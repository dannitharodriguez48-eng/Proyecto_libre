# Archivo Nocturno

portal sobre el terror: de qué trata, tipos de terror con una historia por cada uno y terror del mundo.
Tecnologías: HTML, CSS, JavaScript y Bootstrap 5.3.8 (por CDN).

Ejemplos de Bootstrap usados: heroes (Por qué este tema), features (De qué trata el terror),
carousel (Terror del mundo), modals, navbar y list-groups; tipos de terror en tarjetas con modal.

## Estructura
```
portal-terror/
├── index.html
├── css/styles.css
├── js/main.js
└── images/ (portada, una imagen por tipo de terror, imágenes del carrusel, goteo, telaraña, murciélago y favicon)
```

## Publicar en GitHub Pages
Settings → Pages → Deploy from a branch → main → / (root).
